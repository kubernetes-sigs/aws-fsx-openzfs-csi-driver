# Driver Options
There are several driver options that may be passed as arguments when deploying the driver.

| Option argument             | value sample                                      | default                                             | Description                                             |
|-----------------------------|---------------------------------------------------|-----------------------------------------------------|---------------------------------------------------------|
| endpoint                    | tcp://127.0.0.1:10000/                            | unix:///var/lib/csi/sockets/pluginproxy/csi.sock    | The socket on which the driver will listen for CSI RPCs |
| logging-format              | json                                              | text                                                | Sets the log format. Permitted formats: text, json      |
| cluster-name                | my-cluster                                        |                                                     | Name of the cluster. With `cluster-tag-key`, every AWS resource the controller creates gets the tag `<cluster-tag-key>=<cluster-name>`. See [cluster tag isolation](./cluster-tag-isolation.md) |
| cluster-tag-key             | eks:eks-cluster-name                              |                                                     | Key of the cluster tag. Set it together with `cluster-name` |
| cluster-tag-isolation       | enforce                                           | disable                                             | `disable`: default behavior, plus the cluster tag on new resources; adds the driver tag to root volumes of file systems the controller created. `backfill`: requires `cluster-name` and `cluster-tag-key`; tags existing resources the controller created for this cluster; does not filter discovery. `enforce`: requires `cluster-name` and `cluster-tag-key`; refuses resources that lack this cluster's tag value; does not sweep |
| extra-tags                  | team=storage,env=prod                             |                                                     | Tags added to every AWS resource the controller creates. Not used to find, filter or isolate resources, and not the cluster tag. StorageClass and VolumeSnapshotClass `Tags` override them |
